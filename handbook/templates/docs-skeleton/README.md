# docs/ skeleton

Copy these into a new project's `docs/` and fill them in. The headings are the
contract; the prompts under each are what the section must answer.

A section you cannot fill in yet is a section that says **"not decided"** with a
named owner -- not a section you delete. Deleting it hides the gap.

Working examples of every one of these live in the `bytelab-yocto-template`
repository. Copy from there in preference to writing from scratch.
